# MYTHH Frontend

Next.js app for the swipe-based myth feed.

```bash
nvm use 22
npm install
npm run dev
```

Runs at `http://localhost:3000` and talks to `http://localhost:3001/api/v1`.

Keep the backend running, and keep `FRONTEND_URL=http://localhost:3000` in the backend `.env` so Google sign-in can return here.
